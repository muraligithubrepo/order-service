-------------------------------------------------------------------------------------
dockerFile:
------------
1.FROM : base Image
2.WORKDIR : setting workdire for further Instruction
3.COPY: to use for copying the jar etc.
4.RUN :  install pkg, compilie, create layer
5.ENV : at build/run time , to pass env varibles
6.ARG  : build time variable
7.EXPOSE : port exposing
8.ENTRYPOINT  : fixed executable ["java", "-jar", "app.jar"]
9.CMD  : default command to run app
10.HEALTHCHECK  : to check health periodically


Images:
------------
1. docker build -t myapp:1.0  .
2. docker build -f docker/DockerFile.prod -t myapp:1.0  .
3. docker images
4. docker tag <OLDNAME:TAGE>  <NEWNAME:TAG>
5. docker login
6. docker push <IMAGE_NAME:TAG>
7. docker rmi <IMAGE_NAME:TAG>
8. docker pull <IMAGE_NAME:TAG>
9. docker history <IMAGE_NAME:TAG>
10.docker save -o app.tar vijayrathor/oder_service:1.0.0
11. docker load -i app.tar


12: No cache
13: arg
14: env
15: --build


Container:
--------------
Running instance of Image called Container.

1. docker run  -p <HOST:CONTAINER> <IMAGE_NAME>
2. docker run --name <CONTAINER_NAME>  -p <HOST:CONTAINER> <IMAGE_NAME>
3. docker run -d --name <CONTAINER_NAME>  -p <HOST:CONTAINER> <IMAGE_NAME>
4. docker ps
5. docker ps -a
5. docker stop <CONTAINER_NAME>/<CONTAINER_ID>
5. docker restart <CONTAINER_NAME>/<CONTAINER_ID>
5. docker start <CONTAINER_NAME>/<CONTAINER_ID>
6 docker rm <CONTAINER_NAME>/<CONTAINER_ID>
7. docker rm web_app2 --force
8. docker logs -f --tail <#_OF_LINES>  <CONTAINER_NAME>/<CONTAINER_ID>
9. docker inspect <CONTAINER_NAME>/<CONTAINER_ID>
10. docker stats
11. docker exec -it <CONTAINER_NAME>/<CONTAINER_ID> sh  : enter inside container
12. docker top <CONTAINER_NAME>/<CONTAINER_ID>
